# تطوير الشخصية

رحلة ٩٠ يوماً مع غرفة عمليات إشرافية، من **أبو دانة للبرمجة**.

- الموقع: https://shabiot2.github.io/tatweer/
- تطبيق الأندرويد: https://github.com/shabiot2/tatweer/releases/latest/download/tatweer.apk

يعمل بلا خوادم ولا مفاتيح API: البيانات تُحفظ على الجهاز، ويمكن ربط الأجهزة عبر مساحة سرية مشفّرة في حساب GitHub.

البنية:
- `index.html` الموقع كاملاً في ملف واحد، و`sw.js` لتشغيله بلا إنترنت.
- `android/` تطبيق أندرويد خفيف يفتح الموقع ويضيف تذكيراً يومياً من الجوال.
- `.github/workflows/android.yml` يبني ملف APK وينشره في الإصدارات تلقائياً.
